# 🌌 WELCOME TO XYRIS I

### Not Just an Assistant. An Intelligent Digital Companion.

</div>

**XYRIS I** is an advanced personal AI companion designed to bring intelligent interaction, computer automation, environmental perception, persistent memory, and multimodal capabilities into one unified desktop ecosystem.

Inspired by the idea of a truly intelligent digital assistant, XYRIS I combines conversational AI with practical system-level capabilities.

It is designed to move beyond answering questions — enabling users to interact with their computers, manage tasks, explore information, automate workflows, and engage with their environment through natural interaction.

> ⚡ **The Vision:** Build an intelligent system that can understand, perceive, reason, interact, remember, and continuously improve its capabilities.

# 🚀 INSTALLATION & SETUP

<div align="center">

### Initialize Your XYRIS Environment

</div>

## 📋 System Requirements

| Requirement | Specification |
|---|---|
| Operating System | Windows / macOS / Linux |
| Python | 3.11 or above |
| RAM | 8 GB recommended |
| Microphone | Required for voice interaction |
| Camera | Required for camera and gesture features |
| Internet | Required for cloud AI and online services |
| Gemini API Key | Required for Gemini-powered functionality |

*Optional capabilities may have additional hardware or dependency requirements.*

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Sudhakar-2005/XYRIS-I.git
```

```bash
cd XYRIS-I
```

## 2️⃣ Create a Virtual Environment

### Windows

```bash
py -3.11 -m venv .venv
```

```bash
.venv\Scripts\activate
```

### macOS / Linux

```bash
python3.11 -m venv .venv
```

```bash
source .venv/bin/activate
```

## 3️⃣ Install Dependencies

```bash
python -m pip install --upgrade pip
```

```bash
python -m pip install -r requirements.txt
```

## 4️⃣ Install Browser Dependencies

Install the Playwright browsers required by browser automation:

```bash
python -m playwright install chromium firefox
```

## 5️⃣ Configure API Credentials

Create:

```text
config/api_keys.json
```

Example:

```json
{
  "gemini_api_key": "YOUR_GEMINI_API_KEY"
}
```

⚠️ Never commit API keys or other secrets to GitHub.

## 6️⃣ Launch XYRIS I

```bash
python main.py
```

On Windows, the repository also includes:

```bash
run.bat
```

# 🛡️ SECURITY & PRIVACY

Security is an important part of an assistant capable of interacting with a user's computer.

XYRIS I includes several mechanisms designed to control and manage operations.

| Security Component | Purpose |
|---|---|
| 🔐 Permission Ledger | Track operation permissions |
| ✅ Confirmation Gates | Require confirmation for selected actions |
| 🛡️ Safety Manager | Coordinate safety controls |
| 🔍 Action Verifier | Verify execution outcomes |
| ↩️ Undo Support | Provide recovery mechanisms |
| 🚨 Emergency Stop | Stop spatial interaction immediately |

### Important Security Practices

- Keep API credentials out of public repositories.
- Review permissions before enabling system automation.
- Grant camera and microphone access only when needed.
- Avoid exposing the remote dashboard to untrusted networks.
- Review potentially destructive actions before execution.
- Treat generated AI responses as untrusted until verified.
